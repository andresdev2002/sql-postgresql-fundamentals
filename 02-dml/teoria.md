DML (Data Manipulation Language).
Si DDL construye el esqueleto (tablas, columnas, restricciones), DML trabaja con los datos que viven dentro de ese esqueleto ya construido. Los 4 comandos son:

Comando	Qué hace
INSERT	Agrega una fila nueva
SELECT	Consulta/lee datos existentes
UPDATE	Modifica datos de filas ya existentes
DELETE	Elimina filas
