DDL = Data Definition Language 

Define la estructura de la base de la base datos: Tablas, columnas, tipo de datos y reglas de integridad. 

Comandos principales 

CREATE	Crea una tabla, base de datos, índice, etc.
ALTER	Modifica la estructura de algo que ya existe
DROP	Elimina completamente una tabla, base de datos, etc.
TRUNCATE	Vacía todos los datos de una tabla, pero conserva su estructura
 ==============================================
 Sirven para definir — es decir, crear, modificar o eliminar — la estructura de la base de datos.
 ================================================

Comandos SQL
